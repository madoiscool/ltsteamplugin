LuaTools local harness

Checks public/luatools.js in an ordinary browser — no Steam, Millennium or controller needed. The pages load the real file and stand in for the client with window.Millennium (the CDP bridge) and a fake standard-mapping gamepad.

Run it

cd ltsteamplugin            # repository root
python -m http.server 8765  # or: npx --yes serve -l 8765

Then open:

  • gamepad/store/index.html — mock Big Picture store page
  • early.html — same script evaluated after <head> is removed

Store page variants

Add ?mode= to the store page to exercise the cases seen in the wild:

?mode=PageExpected
bpm (default)BasicUI touch, all containers, store header rowBPM; header icon + stack in #FeatureTarget_interest-buttons
bpm-path-onlyno BasicUI class, URL still under /gamepad/still BPM (URL signal); same UI
bpm-minimalonly #gamepadPurchaseOptionsBPM; stack moves into that container
bpm-noheaderno store header row (as in the gamepad UI)BPM; no icon button, START opens the menu
desktopDesktopUI, no Big Picture containersnot BPM; header icon only, no button stack

Driving the pad

Presses go through window.__pad. Hold a button for a couple of hundred milliseconds — the plugin samples the pad once per animation frame, so an instantaneous flick can fall between samples. 

// START (index 9) opens the menu when the page has no header icon button
window.__pad.buttons[9].pressed = true;
setTimeout(() => (window.__pad.buttons[9].pressed = false), 250);

// d-pad down / up / left / right
[13, 12, 14, 15].forEach((i, n) =>
  setTimeout(() => {
    window.__pad.buttons[i].pressed = true;
    setTimeout(() => (window.__pad.buttons[i].pressed = false), 200);
  }, n * 600)
);

// B (index 1) closes the topmost overlay
window.__pad.buttons[1].pressed = true;
setTimeout(() => (window.__pad.buttons[1].pressed = false), 250);

window.GamepadNav.isConnected(); // true when the plugin has picked the pad up

Keep the page visible: Chromium suspends animation frames and throttles timers in background tabs, so the poll loop stops and presses are missed.

Then, for real

The harness cannot prove CEF injection or Steam's own focus tree. With Millennium installed, open Steam in Big Picture mode and check the store home and a game page: the header icon, the Add via LuaTools / Restart Steam row above the wishlist buttons, START opening the LuaTools menu, d-pad moving the highlight inside it, and B closing it.
