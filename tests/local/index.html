LuaTools local harness

Manual checks for public/luatools.js in an ordinary browser — no Steam, Millennium or controller required. Both pages load the real file and stand in for the client with window.Millennium (the CDP bridge) and a fake standard-mapping gamepad. Serve the repository root first: python -m http.server 8765.

Big Picture store page

tests/local/gamepad/store/index.html — expect:

  • a LuaTools icon button in the store header, with img.src starting data:image/png;base64,
  • a .luatools-bpm-stack inside #FeatureTarget_interest-buttons holding Add via LuaTools and Restart Steam
  • clicking the header button opens the settings overlay, showing the same icon
  • d-pad down/up (buttons 12/13), either stick, or window.__pad.buttons[12].pressed = true moves the highlighted control; B (button 1) closes the overlay

Evaluated without <head>

tests/local/early.html — the store-home timing that used to abort the whole script. Expect the header button and its icon to appear anyway (window.__LuaToolsInjected === true).
